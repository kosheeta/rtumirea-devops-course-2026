**1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?**

В Git ветка — это просто небольшой указатель на commit, поэтому её создание происходит быстро и локально. В SVN ветки создаются в центральном репозитории как копии дерева файлов, поэтому это требует обращения к серверу.

**2. Можно ли в SVN сделать коммит без интернета? Почему?**

Нет, если сервер находится удалённо. SVN — централизованная система, поэтому commit должен попасть на сервер. В Git commit можно сделать без интернета, потому что весь репозиторий находится локально.

**3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?**

SVN может быть удобнее, если нужен строгий централизованный контроль, используется много больших бинарных файлов или компания уже имеет большую SVN-инфраструктуру и нет необходимости переходить на Git.
